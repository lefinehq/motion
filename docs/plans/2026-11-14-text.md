# Plan: text in scenes

**Goal:** step 5 of [the .aep-to-frames plan](2026-11-14-aep-to-frames.md). Text layers are set from font assets with full style ([D33](../design/decisions.md#d33-text-is-shaped-from-font-assets)), and text animators move, scale, turn, fade and recolour characters, words or lines. The first sample needs a three-line title in Lato-Black 55 with a grey stroke, centred, whose lines rise and fade in one at a time from a range selector based on lines.

It ships in two pull requests: style and layout first, then animators.

## 5a. Style and layout

**Format.**

| Key | Where | What |
|---|---|---|
| `fonts` | scene | Font files and folders, relative to the scene file. Inter ships built in as `Inter Variable`. |
| `text`, `font`, `fill` | layer | The words, the base font (family or PostScript name, size, weight) and the base fill, as today. |
| `style` | layer | Character and paragraph style for the whole text. |
| `runs` | layer | `[{"range":[0,4], …character style}]`: overrides for a range of characters, counted in Unicode scalar values. |
| `paragraphs` | layer | One object of paragraph style per paragraph, in order; the paragraphs are split at `\n`. |
| `box` | layer | `[w, h]`: box text that wraps inside the box from the layer's origin; point text without it. |

The style keys are one table (`crates/motion-format/src/text.rs`): name, level (character or paragraph), accepted value and a typed setter.

- **Character:** `font`, `fill`, `stroke`, `stroke-width`, `paint` (`fill-over` or `stroke-over`), `tracking` (thousandths of an em), `leading` (`auto` or px), `baseline` (px), `caps` (`normal`, `small`, `all`, `all-small`), `faux-bold`, `faux-italic`.
- **Paragraph:** `align` (`left`, `right`, `center`, `justify-left`, `justify-right`, `justify-center`, `justify-all`), `indent-first`, `indent-start`, `indent-end`, `space-before`, `space-after`, `auto-leading`.

**Geometry.** A text layer's own coordinates are the layout's: for point text, the origin is where the first line's baseline starts, as the project stores it. The layer's box is the layout's bounds, which may start at negative coordinates, and `anchor` rests at the box's centre. Authored scenes therefore centre their text as they do now, and imported anchors keep their stored values. Layer boxes become rectangles (`kurbo::Rect`) everywhere a rest or an `at` resolves.

**Scene.** `compile` takes a `motion_text::Typesetter` and returns a `Result`: a missing font is an error naming the faces there are, never a fallback. The text node keeps its `TextLayout` (lines, glyph runs, clusters) and each run's paints. `ApproxTextMeasure` is removed.

**Engine.** `Session` builds the font set from `FontSet::builtin()` and the scene's `fonts`, resolved against the scene file's folder.

## 5b. Animators

An animator is an item of the text layer's `animate` list. Its kind key holds its selectors, and its properties are the offsets it applies:

```json
"animate":[{"animator":[{"range":"line","offset":0,"anim":{"offset":[{"t":"0.48s","v":0},{"t":"2.76s","v":1}]}}],"position":[0,75],"opacity":0}]
```

- **Selectors:** `range`, whose kind key holds what it counts (`char`, `char-no-space`, `word`, `line`). Properties `start`, `end` and `offset` (0 to 1 of the units), `amount`, `smooth`, `ease-high` and `ease-low`. Settings `shape` (`square`, `ramp-up`, `ramp-down`, `triangle`, `round`, `smooth`) and `mode` (`add`, `subtract`, `intersect`, `min`, `max`, `difference`).
- **Offsets:** `position` (`x`, `y`), `anchor`, `scale`, `rotate`, `opacity`, `fill`, `stroke`, `stroke-width` and `tracking`. Each unit takes the offset times its selection amount. Opacity and scale blend from their rest toward the animator's value, and position adds.
- **Evaluation:** per glyph, at the layer's time. Glyphs keep their layout positions; an animator's transform turns each character about its own anchor point, at its advance's centre on the baseline. Tracking shifts the characters after it on the same line.

`ItemKind` gains a primary that is a setting (the selector's unit) and one that holds items of another table (an animator's selectors).
